Chính sách quyền riêng tư HugeRows

HugeRows do Anther phát hành. Cập nhật lần cuối: 23/11/2026. Nếu bản này khác bản tiếng Anh, bản tiếng Anh được dùng làm chuẩn.

1. File của bạn ở lại trên máy bạn

HugeRows mở và phân tích file hoàn toàn trên thiết bị của bạn. Nội dung file bạn mở, từ khóa tìm kiếm và câu lệnh SQL không bao giờ được gửi cho chúng tôi hay bất kỳ ai. HugeRows không có tài khoản và không cần kết nối internet để hoạt động.

2. Những gì HugeRows không làm

  • Không thu thập số liệu sử dụng, không gửi báo cáo lỗi.
  • Không quảng cáo, không theo dõi.
  • Không tải lên nội dung file, tên file hay dữ liệu sử dụng.
  • Không tự kiểm tra bản cập nhật. Bản trên Microsoft Store do Store cập nhật.

3. Dữ liệu lưu trên máy bạn

  • File tạm. HugeRows ghi một bản làm việc vào thư mục tạm (%TEMP%\hugerows) khi file bị nén, dùng bảng mã khác UTF-8, hoặc là file nhỏ trên ổ mạng hay ổ tháo rời. Kết quả SQL cũng nằm ở đó. Các file này bị xóa khi bạn đóng file hoặc đóng ứng dụng; phần còn sót lại sau khi ứng dụng bị tắt đột ngột được dọn ở lần chạy sau.
  • Bản sao bạn yêu cầu. Với file lớn trên ổ mạng hoặc ổ tháo rời, bạn có thể cho HugeRows chép nó vào một thư mục bạn chọn. Bản sao đó (tên hugerows-*.local) bị xóa khi bạn đóng file. Nếu ứng dụng bị tắt đột ngột, bản sao có thể còn lại và xóa đi được an toàn.
  • Xuất file. Trong lúc xuất, HugeRows ghi vào một file tạm cạnh nơi bạn chọn (tên có .hvtmp-) rồi đổi tên khi xuất xong. Nếu ứng dụng bị tắt đột ngột giữa chừng, file đó có thể còn lại và xóa đi được an toàn.
  • Tùy chọn. Danh sách file mở gần đây, lịch sử SQL, cách sắp xếp cột của từng file, cài đặt giao diện và vị trí cửa sổ được lưu trong hồ sơ người dùng trên máy. Những dữ liệu này gồm đường dẫn file và nội dung câu lệnh bạn đã chạy, nhưng không gồm nội dung file. Bạn xóa được danh sách gần đây ngay trong ứng dụng. Gỡ bản Microsoft Store sẽ xóa các dữ liệu này; bộ cài từ trang web của chúng tôi sẽ hỏi bạn có muốn xóa không.
  • License key. Nếu bạn kích hoạt HugeRows Pro bằng license key, key được lưu trong hồ sơ người dùng và được kiểm tra offline. Key chứa tên và email bạn cung cấp khi mua, để bạn nhận ra giấy phép của mình.

4. Khi nào có dùng internet

Bản thân HugeRows không tạo kết nối mạng nào, trừ các trường hợp sau:

  • Bản Microsoft Store. Ứng dụng hỏi Microsoft Store trên máy bạn xem bạn đã mua bản đầy đủ chưa. Việc kiểm tra này do Windows và Microsoft thực hiện theo chính sách quyền riêng tư của Microsoft; HugeRows chỉ nhận câu trả lời có hoặc không.
  • Liên kết bạn bấm. Nút "Mua" mở trang Store hoặc trang web của chúng tôi trong trình duyệt.
  • File trên ổ mạng. Khi bạn mở file từ một vị trí mạng, Windows đọc nó qua mạng như với mọi ứng dụng khác.
  • SQL bạn tự viết. Truy vấn chạy trong một bản DuckDB nhúng sẵn. HugeRows tắt việc DuckDB tự tải tiện ích mở rộng. Câu lệnh mà bạn chủ động cài tiện ích hoặc đọc từ một địa chỉ web sẽ được DuckDB thực hiện đúng như bạn viết.

5. Mua hàng

Giao dịch mua do Microsoft Store hoặc đơn vị thanh toán của chúng tôi xử lý. Chúng tôi chỉ nhận thông tin cần để cấp giấy phép (tên, email và mã đơn hàng), không nhận thông tin thẻ của bạn.

6. Thay đổi chính sách

Nếu một phiên bản HugeRows sau này thay đổi bất kỳ điều gì ở trên, trang này sẽ được cập nhật và ngày ở đầu trang sẽ đổi.
