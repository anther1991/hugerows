HugeRows Privacy Policy

HugeRows is published by Anther. Last updated: November 23, 2026.

1. Your files stay on your computer

HugeRows opens and analyses files entirely on your device. The contents of the files you open, your search terms and your SQL queries are never sent to us or to anyone else. HugeRows has no account system and needs no internet connection to work.

2. What HugeRows does not do

  • No analytics, telemetry or crash reporting.
  • No advertising and no tracking.
  • No uploading of file contents, file names or usage data.
  • No automatic update checks. The Microsoft Store version is updated by the Store.

3. Data stored on your device

  • Temporary files. HugeRows writes a working copy to your temporary folder (%TEMP%\hugerows) when a file is compressed, uses a text encoding other than UTF-8, or is a smaller file on a network or removable drive. SQL results are stored there too. These files are deleted when you close the file or the application; anything left behind after a crash is removed the next time HugeRows starts.
  • Copies you ask for. For a large file on a network or removable drive you can have HugeRows copy it to a folder you choose. That copy (named hugerows-*.local) is deleted when you close the file. If the application is closed abruptly it can remain in that folder and is safe to delete.
  • Exports. While an export is running, HugeRows writes to a temporary file next to the destination you chose (its name contains .hvtmp-) and renames it when the export finishes. If the application is closed abruptly during an export, that file can remain and is safe to delete.
  • Preferences. The list of recently opened files, your SQL history, the column layout per file, your interface settings and the window position are stored locally in your user profile. These include file paths and the text of queries you ran, but not file contents. You can clear the recent list inside the app. Uninstalling the Microsoft Store version removes this data; the installer from our website asks whether to remove it.
  • License key. If you activate HugeRows Pro with a license key, the key is stored in your user profile and checked offline. The key contains the name and email address you gave when buying, so that you can identify your own license.

4. When the internet is used

HugeRows itself makes no network connections. The only exceptions are:

  • Microsoft Store version. The app asks the Microsoft Store on your device whether you own the full version. That check is handled by Windows and Microsoft under Microsoft's privacy policy; HugeRows receives only a yes/no answer.
  • Links you click. The "Buy" button opens the store page or our website in your browser.
  • Files on network drives. If you open a file from a network location, Windows reads it over your network as it would for any other application.
  • SQL you write. Queries run in an embedded copy of DuckDB. HugeRows turns off DuckDB's automatic download of extensions. A query in which you explicitly install an extension or read from a web address is carried out by DuckDB as you wrote it.

5. Purchases

Purchases are processed by Microsoft Store or by our payment provider. We receive the information needed to issue your license (name, email address and order number) and do not receive your card details.

6. Changes to this policy

If a later version of HugeRows changes any of the above, this page will be updated and the date at the top will change.
